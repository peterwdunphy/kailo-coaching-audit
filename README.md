# Kailo Coaching Hub Audit

Product review of the Kailo coaching hub and the architecture for its data
and enrichment platform.

## Build

```bash
tectonic audit.tex     # -> audit.pdf
```

Requires [Tectonic](https://tectonic-typesetting.github.io/). No other setup.

## Layout

- `audit.tex` --- main document (product goals, product audit, wording).
- `platform.tex` --- the Data & Enrichment Platform section, with three TikZ
  diagrams: (1) roster/meet/team sourcing, (2) course weather + hill info,
  (3) HS-to-college linkage.

The audit.pdf is committed so it can be read without a LaTeX install.
